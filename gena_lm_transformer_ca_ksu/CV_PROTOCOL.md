# KSU 交叉验证修正说明

基线：main 提交 `0d4174c412825ab816d10069c41b40dadf66770f`。

## 新的数据边界

1. 对未欠采样的完整训练集执行固定 seed=42 的 StratifiedKFold。
2. 每折仅将训练索引对应的 pooled GENA-LM 特征及标签交给 KSU。
3. KSU 返回的是折内局部索引；通过 `train_idx[local_idx]` 映射回原始训练集。序列、mask、结构、标签使用同一索引；代码检查 KSU 返回值与索引的一致性。
4. SG 仅在该折 KSU 保留的训练数据上拟合。验证折完全保留原始样本和类别分布，只进行 transform 和 predict。
5. 保持原模型结构、学习率、训练轮数、batch size 与 shuffle=False。外层验证数据不再传给 fit，避免将来增加回调时不慎用其选择模型。
6. 分类阈值预先固定为 0.5；移除按论文 SN/SP 目标或验证 MCC 搜索阈值的路径。外层标签只用于最终指标和 ROC。固定阈值是明确、无阈值调优泄漏的基线，但欠采样后的概率不一定校准，0.5 不保证适合所有部署代价。
7. 独立测试仍使用完整训练集重新执行 KSU、拟合 SG、训练最终分类器，随后只评估独立测试集，使用相同固定阈值。测试标签不参与训练或阈值选择。

若后续确需调阈值，应另立实验协议：每个外层训练折内部再划分校准集或生成内部 OOF，KSU/SG/训练都不能接触内部留出标签；只用内部预测确定该外层模型阈值，随后冻结。最终部署阈值仅用训练数据内部校准确定。不能先观察此次外层结果再挑一个最优固定阈值并继续声称外层结果无偏。

## 审计输出和索引

- 输出路径增加 `train_fold_ksu_fixed_threshold_v2`，与旧结果隔离。
- 每折 `foldN_indices.npz` 保存原始训练索引、KSU 局部索引、保留的原始索引和原始验证索引。
- 每折 JSON 记录欠采样前后与验证集的类别统计。
- `oof_predictions.npz` 按原始行号保存概率、标签、折号和固定阈值。调试只跑首折时未评估行是 NaN、折号为 -1，不能当完整十折结果使用。
- 最终独立测试目录保存 `final_ksu_original_indices.npy`。
- 原 loader 依赖 FASTA 与结构文件的记录顺序，不按记录 ID 重新排序。此次逐一检查仓库中的 56 对 split 文件，序列/结构 header 顺序全部一致；这是当前数据快照的核查，未来替换数据仍需核对顺序。运行时新增各分支样本数、标签维度/取值和 embedding/mask 形状校验。
- 原始 GENA-LM 是冻结的逐样本特征抽取，可复用完全相同模型、分词配置及样本顺序的原始特征。全局 KSU 结果、SG 拟合产物不能作为新十折输入。
- 为尽量保持原有数值行为，保留训练/测试共同 padding 长度的流程；没有使用测试标签，但尚未改造成完全不读取测试输入形状的协议。

## 验证与必须重跑的实验

轻量回归验证：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -s tests -v
python -m compileall -q gena_lm_transformer_ca_ksu tests
```

测试执行真实 sklearn KSU，覆盖十折验证覆盖率、局部到原始索引映射、所有特征分支对齐、验证标签扰动不影响训练采样、错位输入拒绝；AST 检查主流程没有验证阈值搜索且全局 KSU 只用于最终训练。它们不替代 TensorFlow/GENA-LM 端到端实验。

必须重新训练完整十折：所有使用旧“先全局 KSU 再划折”的数据集、重复种子、消融和相关比较。ROC/AUC 同样必须重跑，因为训练样本与验证分布都变了。SN/SP/P/ACC/BA/MCC/F1 还受固定阈值影响。旧折模型不能仅重算阈值后充当修正结果。

必须按新协议重新报告独立测试阈值指标。若保留了原最终模型的测试概率和标签，且能确认最终全量 KSU、SG、训练配置/样本完全一致，可用固定 0.5 直接重新计算测试阈值指标，AUC 不受阈值改变影响；推荐完整执行脚本，统一生成新审计记录。最终模型本身不因外层 KSU 修正而必然改变，不宣称 AUC 或性能提高。

正式执行（原默认数据集、10 折、30 epochs）：

```bash
cd gena_lm_transformer_ca_ksu
python run_ksu_gena_lm_transformer_ca.py
```

对不同数据集按原入口更换 dataset。先用小规模数据确认依赖、维度与训练可运行，再执行全部正式实验；首折调试结果不能用于正式十折报告。保持比较方法的原始评估样本、split、阈值协议一致，并报告类别比例。若按相邻/同源序列需要分组划分，需另行设计，当前 StratifiedKFold 修正并不证明不存在生物学同源性泄漏。

本次未运行真实神经网络训练或重新估计性能，无任何提升结论。
